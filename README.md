# 📂 Immi-Sync  

**Immi-Sync** is a case and document management platform built for immigration consultants. It enables consultants to manage clients, track case progress, and securely share documents in one centralized system. Designed to streamline workflows and improve collaboration, Immi-Sync reduces manual overhead and enhances transparency across cases.

## ✨ Features  
- 👥 Client and case management dashboard  
- 📑 Secure document upload and sharing  
- 📊 Case progress tracking with status updates  
- ☁️ Cloud-based storage powered by GCP  
- 🎨 Clean, responsive UI built with React + Tailwind  

---

## 🛠️ Tech Stack  
- **Frontend**: React, JavaScript, TailwindCSS  
- **Backend**: Express, Node.js  
- **Database**: MongoDB  
- **Cloud**: Google Cloud Platform (GCP)
